# Archived Forgejo configuration

CrossHook moved collaboration (issues, PRs, CI, and releases) back to GitHub:
<https://github.com/yandy-r/crosshook>. The repository is public, so GitHub
Actions usage is free and the original reason for self-hosting no longer applies.

This directory keeps the former `.forgejo/` workflows, issue forms, and PR
template for reference only. Forgejo does not read workflows from this path, so
nothing here runs. The active equivalents live under `.github/`.

`Forgejo #N` references in older docs, plans, and code comments point at the
retired tracker (`git.home.rfamily.dev/yandy/crosshook`) and are historical.
