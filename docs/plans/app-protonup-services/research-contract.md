## 1. Wire-key rule (Tauri arg casing)

Tauri 2.11 `#[tauri::command]` defaults to `ArgumentCase::Camel` (tauri-macros-2.6.2 `command/wrapper.rs:51,505-513`): each Rust snake_case param is looked up by its **lowerCamelCase** key only — no snake fallback (`tauri-2.11.2/src/ipc/command.rs:88-97`, `deserialize_option` :134-142 turns a missing key into `None`). DTO payloads (`request`, `version`) and event payloads serialize with their serde attrs (snake_case unless renamed). **Frozen contract = the camelCase keys below.**

### 1.1 Pre-existing caller drift (do NOT "fix" by renaming Rust params)

These callers pass snake_case keys that native Tauri **silently drops** (mocks read/ignore them too, so browser dev mode hides it):

- `hooks/useProtonManager.ts:152` `protonup_resolve_install_roots { steam_client_install_path }` → should be `steamClientInstallPath` (falls back to `None`).
- `hooks/useProtonManager.ts:193-195` and `hooks/useProtonUp.ts:97-100` `protonup_list_available_versions { force_refresh }` → forced refresh is silently ignored; only `provider` (same spelling) works.
- `components/settings/ProtonManagerDefaultsSection.tsx:62-64` same snake `steam_client_install_path`.

Correct camelCase callers (the shape to keep): `useProtonMigration.ts:33-35` (`steamClientInstallPath`), `useProtonUp.ts:156-159` (`communityVersion`, `steamClientInstallPath`), `useProtonManager.ts:242-245,260,269-272,283-286` (`request`, `version`, `opId`, `toolPath`, `steamClientInstallPath`), `useUmuCoverage.ts:22` (`appId`). Migration must preserve param names/spelling exactly; fixing the frontend keys is a separate follow-up, not part of the move.

## 3. Event: `protonup:install:progress`

- Emitted by `tauri/commands/protonup.rs:282-287`: a `tokio::spawn` pump forwards a `broadcast` channel (cap 64, lossy under lag, core/protonup/progress.rs:12) to `app.emit("protonup:install:progress", &progress)`. **No sentinel after the loop** — the orchestrator emits terminal `Phase::Done|Failed|Cancelled` before the sender drops; that is the frontend's terminal signal.
- Payload `ProtonInstallProgress` (core/protonup/progress.rs:29-36), snake_case fields, phase kebab-case: `{ op_id: string, phase: 'resolving'|'downloading'|'verifying'|'extracting'|'finalizing'|'done'|'failed'|'cancelled', bytes_done: number, bytes_total?: number|null, message?: string|null }`. TS mirror: `types/protonup.ts:85-101`; unknown phases are dropped client-side (`hooks/useProtonInstallProgress.ts:5-18,45`).
- Consumer chain: `useProtonInstallProgress(opId)` → `InstallProgressBar` (`components/proton-manager/InstallProgressBar.tsx:54-71`; auto-dismiss `done` after 4s; `failed`/`cancelled` sticky) rendered per `manager.activeOpIds` in `ProtonManagerPanel.tsx:396-399`. Cancel flow relies on the `cancelled` terminal event, not on the bool return (`useProtonManager.ts:252-261`).
- Related event (migration results reach the UI this way, not via returns): `profiles-changed` `{ reason: {kind:'migrated',…}, names }` pumped by `tauri/src/startup_bridge.rs:22-41` from the app `EventBus` (`ProfileWriter` commits with `ProfileChangeReason::Migrated`); drives `useProfileHealth` revalidation (`hooks/useProfileHealth.ts:285`).

## 6. Command pin tests

Convention: `#[cfg(test)] mod tests { #[test] fn command_names_match_expected_ipc_contract() { let _ = cmd_name; … } }` — async commands can't be fn-pointers so naming them pins the exported IPC symbol. Existing: `tauri/commands/steam.rs:39-49`, `profile/tests/contract.rs`, `launch/tests/contract.rs`, `health/tests.rs`, `startup/tests.rs`, plus inline `mod tests` in 16 other command files. **`protonup.rs`, `migration.rs`, `umu_database.rs` have no tests module today** — the migration should add pin tests listing all 15 names (and keep `ProtonInstallRegistry` removal from `lib.rs:71-73` in sync with the new `JobRegistry` fold).

Ownership note (from SecurityResearch, to fold into contracts): `JobId` is a bearer capability — `JobRegistry` has no owner token (`app/jobs/types.rs:9-11`). AC4 requires a service-side ownership ledger (`op_id`→owner) with the owner derived from Tauri-injected webview identity, never a client-supplied arg; wire shape of `protonup_cancel_install` stays `{opId} → bool`.
